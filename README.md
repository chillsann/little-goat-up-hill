# 小羊上山 · 汉字山能量大冒险

**在线玩**：https://chillsann.github.io/little-goat-up-hill/

![首页](preview/1-home.png)
![登山地图](preview/2-map.png)

依据《小羊上山儿童汉语分级读物》**第 1 级 60 个核心字**重编的识字闯关游戏。
单文件网页 + 60 个真人单字发音 MP3，零依赖、可离线运行（双击 `index.html` 即可）。

## 这一版改了什么

旧版是「听发音 → 4 选 1」的单循环刷题，60 个字从头点到尾，5 岁孩子几分钟就腻；
后 5 关还是自造字表（含「死、恨、惧、俄罗斯」等超纲内容），和教材脱节。

新版按教材重做，把识字包进一条完整的冒险主线：

> 迷雾怪偷走了汉字山的宝石，小羊要从起跑坡一路爬到山顶宝库，
> 每站认字、打怪、拿到徽章，最后自己读完一本小书。

| 维度 | 旧版 | 新版 |
|---|---|---|
| 字表 | 6 关自造字（含超纲字） | 严格对齐教材第 1 级 **60 字、10 册** |
| 编写原则 | 无 | 词语、绘本短句**只用本册及之前学过的字**（教材铁律，有自动校验） |
| 学习闭环 | 只有听音选字 | 剧情 → 认字（象形 / 真人发音 / 组词 / 描红）→ 2 个小游戏 → 自主阅读 → 奖状 |
| 玩法种类 | 1 种 | **5 种轮换**：抢宝石 / 敲迷雾怪 / 谁不见了 / 对对碰 / 词语拼拼乐 |
| 反馈 | 对/错提示 | 连击、飘字、彩带、宝石图鉴、徽章、可保存的奖状、登山进度存档 |
| 画风 | 静态米色卡片 | 手绘 SVG 小羊与迷雾怪、10 站登山地图、宝石与立体按钮 |

## 教材依据

《小羊上山》第 1 级 60 字（3–5 岁，零起点）：

> 一二三四五六七八九十　两只头又了不大小上下　多少白天云山太阳月亮
> 星马牛羊兔虫鸟花草树　地吃看走笑来飞爱是跑　跳高兴快乐好的爸妈我

- **10 册 = 10 个站点**，每册 4–7 个新字（教材各册字数本就不等）
- 每册词语、绘本短句只由「本册及之前」的字组成，例如第 2 本《小小的，大大的》：
  「小草小小的，大树大大的。」「大树小小的，大山大大的。」
  孩子认完几个字就能自己读完一页，成就感是坚持下来的关键
- `node check-data.mjs` 会自动校验：字表 60 字无重复、所有词语/句子无超纲字、
  绘本不出现未学字、60 个真人发音 MP3 齐全

## 一关怎么玩（约 5 分钟）

1. **剧情**：小羊接到任务，迷雾怪放狠话
2. **认字**：图画变汉字 → 点字听真人发音 → 点词语听连读 → 手指在田字格描一描
3. **两个小游戏**：逐册轮换，答对有连击、飘字和星星
4. **我自己读**：点单字听发音，点整句听小羊朗读，句子只用学过的字
5. **领奖状**：点亮新宝石、获得徽章，奖状可保存成 PNG

右下「📖」是 60 格宝石图鉴，点亮的宝石能点读；「给家长的话」里有完整说明。
进度自动保存在浏览器本地。

## 自测

| 参数 | 作用 |
|---|---|
| `?autotest=1` | 页面内自动跑完 10 册全流程，结果写进标题 |
| `?smoke=1` | 各界面与 5 种游戏渲染冒烟 |
| `?audiotest=1` | 检查真人 MP3 加载与 AudioContext 状态 |
| `?preview=map\|learn\|game\|read\|award\|dex\|story&type=gem` | 直接打开某个界面（截图用） |
| `&nofx=1` | 关闭动画（截图用） |

当前结果：全流程 `AUTOTEST_OK gems=60 books=10 games=gem,missing,whack,match,build err=0`；
冒烟 `SMOKE_OK err=0`；发音 `AUDIOTEST_OK mp3=4/4 ctx=running`；数据体检通过。
桌面 1100px 与 500px 小屏均已验证。

## 发音

60 个单字是仓库自带的真人录音（`audio/` 目录），**离线也能听**；
词语与句子由单字录音连读，其余提示音由 WebAudio 实时合成。
首次点击页面会解锁浏览器音频（自动播放策略要求），右上角 🔊 可静音。
