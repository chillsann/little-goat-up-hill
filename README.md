依据《小羊上山儿童汉语分级读物》**1~6 级**重编的识字闯关游戏：
**6 个级别 / 60 册绘本 / 390 个核心字**，每册都有独立的「🎤 跟读全文」关卡。
单文件网页 + 仓库自带真人单字发音，零依赖；双击 `index.html` 即可玩。

## 分级体系

| 级别 | 累计字表 | 本级新增 | 主题 | 参考年龄 |
|---|---|---|---|---|
| 第 1 级 | 60 字 | 60 | 起跑坡 | 3–5 岁 |
| 第 2 级 | 120 字 | 60 | 四季河谷 | 4–7 岁 |
| 第 3 级 | 180 字 | 60 | 森林学校 | 5–8 岁 |
| 第 4 级 | 240 字 | 60 | 机器城堡 | 6–8 岁 |
| 第 5 级 | 310 字 | 70 | 天空之城 | 6–8 岁 |
| 第 6 级 | 390 字 | 80 | 山顶书海 | 6–8 岁 |

- 字表依据公开整理的各级「本级总字表」，按官方分级字数编排；个别整理表缺字用同级高频常用字补齐。
- **绘本为配合游戏的原创改写，不是原书全文**；词语与绘本短句只使用「本级及之前」字表里的字（第 1 级更严格，按「本册及之前」校验）。
- `node check-data.mjs` 自动校验 6 级字数、无重复字、词库、全部 60 册绘本无超纲字。
- 所有级别都可直接选择，进度按级别分别存档；旧版（只有第 1 级）的存档会自动迁移。

## 🎤 跟读全文关卡

读完绘本后进入，是本版新增的核心环节，对应教材「家长读多 → 孩子读多 → 独立朗读」的过渡：

1. **听示范**：逐句点「🔊 听示范」，或点「🔊 听整本」连续朗读全书
2. **我来读**：点「🎤 我来读」调用麦克风录音（最长 9 秒），停止后自动保存
3. **听我的**：回放孩子自己的录音，逐句点亮一颗星星
4. **读好啦**：逐句打卡，全部完成获得「朗读小达人」+6⭐，奖状上也会标注

**有麦克风时，必须逐句录下自己的声音才能打卡并领取奖状**（没录的句子按钮会变灰提示「先录音」）；
只有在麦克风不可用（设备不支持或家长/系统未授权）时，才会开放「✅ 读好啦 / 先不跟读」的降级通道，避免卡住。
录音只存在当前页面内存里，不上传、不写入存档。

## 学习闭环（每册约 6 分钟）

剧情 → 认字（象形 / 发音 / 组词 / 田字格描红）→ 2 个小游戏轮换 → 自主阅读 → **跟读全文** → 奖状

田字格描红内置**标准笔顺引导**：淡色字形模板上标出「① ② ③…」起笔点和方向箭头，告诉孩子每一笔从哪起、往哪写；点「🖌️ 看示范」还会逐笔把字写一遍。笔顺数据（390 字）在构建时注入单文件，离线照样能用。

5 种小游戏：抢汉字宝石 / 敲跑迷雾怪 / 谁不见了 / 汉字对对碰 / 词语拼拼乐。
另有连击、宝石图鉴（390 格按级分组）、徽章、可保存的 PNG 奖状、登山进度。

## 发音方案

- 仓库 `audio/` 下有 **359 个真人单字 MP3**，其中 **233 个**属于 1~6 级字表，离线也能听。
- 其余 **157 个字**自动改用**浏览器中文语音**（`speechSynthesis`，zh-CN）；整句朗读优先用中文语音，语调更自然，没有中文语音时退回单字 MP3 拼读。
- 提示音由 WebAudio 实时合成；首次点击会解锁音频（浏览器自动播放策略），右上角 🔊 可静音。
- 建议用 Chrome / Edge 打开（中文语音支持最完整）。

## 文件结构

```
index.html          成品（单文件，直接双击就能玩）
audio/*.mp3         359 个真人单字发音
src/shell.html      页面骨架 + 手绘 SVG 角色
src/style.css       样式（含选级 / 跟读 / 移动端适配）
src/data.js         1~6 级字表、60 册绘本、词库、字卡图解、游戏配置
src/core.js         分级存档、发音引擎、描红、绘本、跟读录音、奖状
src/games.js        5 种小游戏
src/boot.js         启动、预览、自检入口
build.mjs           打包：node build.mjs → index.html（注入 MP3 清单 + 笔顺数据）
strokes.json        390 字的笔顺数据（笔画 SVG 路径 + 中线），由 fetch_strokes.mjs 从 hanzi-writer-data 抓取
fetch_strokes.mjs   重新拉取笔顺数据用（需要网络）
check-data.mjs      教材数据体检
```

## 自测

| 参数 | 作用 |
|---|---|
| `?autotest=1&level=6` | 自动跑完指定级别的 10 册 |
| `?autotest=1&all=1` | 自动跑完 1~6 级 **60 册**全流程 |
| `?echotest=1&level=3` | 跟读关卡自检（句子数 / 打卡 / 录音能力） |
| `?smoke=1` | 6 级各界面与 5 种游戏渲染冒烟 |
| `?audiotest=1` | 真人 MP3 + 中文语音兜底 + AudioContext |
| `?preview=levels\|map\|story\|learn\|game\|read\|echo\|award\|dex\|parent&level=N` | 直接打开某个界面（截图用） |
| `&nofx=1` | 关闭动画（截图用） |
